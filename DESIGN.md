# Design Direction

## 1. Identity & Product
- **Product:** Automatic Website Generator
- **Target Audience:** Professionals and corporates looking for premium, elegant web solutions.

## 2. Personality & Mood
- **Vibe:** Elegant, Luxurious, Professional, and Corporate.
- **Goal:** The design should communicate high-end value and authority, moving away from generic tech/AI aesthetics.

## 3. Color Palette
- **Primary / Deep Accent (Burgundy):** `#800020`
- **Secondary / Soft Accent (Rose/Red):** `#D45060`
- **Background / Base 1 (Almond/Beige):** `#F3E6D5`
- **Background / Base 2 (Cream):** `#FFF9F2`

## 4. Typography
- **Headings (Display/Serif):** Playfair Display (for elegance and luxury)
- **Body Text (Sans-Serif):** Lato (for clean, professional readability)

## 5. Liveliness Dials
- **ENERGY:** 3 (Bold - strong, striking presence, high-end agency portfolio level impact)
- **RHYTHM:** 3 (Asymmetric, mixed compositions - varied sections, not a repetitive template)
- **MOTION:** 3 (Parallax, pin, choreography - high-end transitions and scroll animations)
